# ЦС Т40Т и Т40К

Источник: `ТЗ_ЦЕЛЬНОСТЕКЛЯННЫЕ_КОНСТРУКЦИИ.docx` и дополнение заказчика о двух ПВХ-подкладках на каждое стекло. Исходный DOCX сохранён без изменений. Иллюстрации находятся в `backend/assets/profiles/T40T-{section,photo}.jpg` и `T40K-{section,photo}.jpg`; оригиналы в Downloads не удалены.

## Геометрия

Координаты в миллиметрах: X вправо, Y вверх. Каждая сторона связывает угол Уn со следующим углом. Для стороны выбирается ровно один вариант: зажим Т40Т с двумя крышками Т40К, пузырьковый RS1002 или свободная сторона.

* Т40Т: высота 40 мм, заход стекла 14 мм. Световой контур смещён внутрь на 40 мм, контур стекла — на 26 мм.
* RS1002: вычет 6 мм по нормали к стороне. В дополнительной настройке можно изменить на 7 мм или другое согласованное значение.
* Между стёклами зазор 3 мм. Равномерные деления распределяются по световому проёму. У крайних стёкол остаётся заход в профиль.
* В редакторе вводятся наружные ширина и высота. Старые световые размеры при открытии переводятся в наружные с сохранением геометрии и ручных стыков; база меняется только при явном сохранении.
* Вогнутые контуры могут дать несколько отдельных стёкол в одной ячейке сетки. Каждое считается отдельно. Самопересечения и схлопывание сторон после вычетов запрещены.
* Версия конфигурации 1 читается без перестановки углов; старый `profiledEdges` сохраняется как комплектация сторон версии 2. У новых заготовок профиль по всему периметру.

## Комплектация и ограничения

Т40Т считается по выбранным сторонам монтажного контура. Т40Т выводится отдельными длинами. На каждый участок приходится две крышки Т40К с припуском по 50 мм. Суммарный метраж округляется вверх до целых палок 3000 мм для одной секции, затем умножается на количество секций; без оптимизации раскроя. Контроль: 2240×600, четыре стороны → 11760 мм → 4 палки; две секции → 8 палок. В покраске повторный припуск не добавляется, крышки объединяются с деталями того же исполнения и RAL. Клипсы, винт и внутренний уплотнитель уже входят в зажимную сборку. Покраска относится только к крышкам выбранного исполнения; Анод/неокрас не включается в заявку на покраску.

Подкладка `CS-PVC-PAD` — внутренний артикул каталога, количество = фактическое число стёкол × 2 × количество конструкций. Скотч без артикула: две полосы × фактическая длина вертикальных и горизонтальных стыков × количество секций. Пересечения воздушных зазоров не учитываются. На эскизе вместо подкладок и скотча выводится только «склейка через скотч» при наличии стыков.

Т40Т выводится без припусков на распил. Точные значения сохраняются в расчёте, отображение размеров округляется до 0,1 мм, площадей — до 0,001 м². Допуск изготовления этим не утверждается. Коммерческая цена ЦС отключена; закупочные цены и вес новых позиций не выдумываются. Дверная фурнитура остаётся следующим этапом.

Контроль: монтажный проём 1755×2835 → световой 1675×2755 → одно стекло 1703×2783; при двух стёклах — 850×2783 каждое. Три стекла в двух конструкциях требуют 12 подкладок.

## Выпуск октябрьских правок

Развёртывание выполняется только после отдельного согласования. До него:

1. Завершить проверки backend, `npm run check`, сборку и браузерные проверки редактора. Проверить PDF, DOCX и XLSX, включая реальные счета №00000047 и №00000051 на копии данных.
2. Зафиксировать текущую ревизию сервера и остановить запись в приложение на время резервного копирования. Сделать согласованную SQLite-копию через `sqlite3 … ".backup …"` (не обычное копирование открытой базы); отдельно сохранить загруженные изображения. Проверить `PRAGMA integrity_check` на копии и убедиться, что резерв доступен вне контейнера.
3. Установить согласованную ревизию и запустить существующий механизм миграций. Новая таблица `customers` содержит `id`, `name`, уникальный `name_key`, `is_active`. Маркер `customer_directory_v1` однократно добавляет только ООО ПРОЗРАЧНЫЕ РЕШЕНИЯ и ООО КРОКНА ИНЖИНИРИНГ. Имена из проектов не импортируются. Повторный запуск не возвращает отключённые или переименованные записи.
4. Проверить `/health`, вход, список заказчиков и права всех суперадминистраторов. Новые/изменённые заказчики выбираются из активного справочника. Неизменённые исторические строки сохраняются; копирование проекта с недоступным заказчиком требует нового выбора. Проверить счёт, эскизы и экспорт обоих контрольных проектов.
5. При откате вернуть прежнюю ревизию. Добавленная таблица совместима со старым приложением. Восстанавливать всю базу из копии можно только при остановленной записи и с учётом данных, появившихся после копирования; не терять новые заказы.

Сохранённые КП не пересчитываются и не переписываются. Новые снимки содержат дополнительные размеры видимых боковых профилей. Наценки, дверные системы и коммерческая цена ЦС этой доработкой не включаются. RS3061 выдаётся по две детали на стык, перехлёст остаётся 11,5 мм. Группировка дополнительных комплектующих изменяет документы, но не исходные строки проекта.
