# Raluma — система для производства стеклянных конструкций

Веб-приложение для ведения проектов, настройки секций, расчёта комплектующих и подготовки производственных листов. Разработано в рамках коммерческого заказа.

## Что есть в репозитории

- `Raluma/src/` — интерфейс на React и TypeScript: проекты, редактор секций, схемы и производственные листы;
- `Raluma/backend/` — FastAPI, SQLAlchemy, расчётный модуль, генерация PDF и тесты;
- `Raluma/docker-compose.yml` — конфигурация развёртывания приложения.

Расчётная логика находится в `Raluma/backend/engine/slide_calc.py`. Проверки API и расчётов — в `Raluma/backend/tests/`.

## Локальная разработка

См. [инструкцию приложения](Raluma/README.md). Для запуска требуются собственные значения `SECRET_KEY` и `INITIAL_ADMIN_PASSWORD`; реальные ключи и данные заказчика не должны попадать в репозиторий.

Внутренние спецификации и документы заказчика не являются частью публичного описания проекта. Перед публикацией исходников и демонстрацией данных следует проверить право на их раскрытие.
