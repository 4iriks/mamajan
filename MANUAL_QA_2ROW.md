# Ручная приемка СЛАЙД 2 ряда

Дата начала: 2026-06-09.

Цель: вручную и полуавтоматически проверить, что СЛАЙД 2 ряда считает и отображает ожидаемо, а прошлые правки по 1 ряду, документам, гостевому режиму, админке и каталогу не сломались.

## Контрольная среда

- Ветка: `feature/guest-mode-registration`.
- Деплой: `https://raluma.tech`.
- Коммит под проверкой: `bddf0a9 Реализовать СЛАЙД 2 ряда`.
- Локальная правка по результатам QA: карточка секции теперь показывает `2 ряда`, а не жестко `1 ряд`.
- Локальный грязный файл вне проверки: `CLAUDE.md`.

## Методика

- Backend-расчет проверяем через stateless endpoint `/api/projects/local/sections/calc` и сверяем с формулами из DOCX.
- HTML preview производственного листа проверяем через `/api/projects/local/sections/preview`.
- UI проверяем браузерным сценарием локально на `http://localhost:5173` с backend `http://localhost:8000`; это проверяет текущий frontend-код до деплоя.
- Важно: для локальной проверки документов нужно открывать именно `http://localhost:5173`, не `127.0.0.1`, потому что CORS backend разрешает `localhost:5173`.
- Project-level документы проверяем через preview/PDF-ссылки приложения и guest smoke.
- Для прошлых правок фиксируем регрессию: гостевой режим, регистрация/перенос, админка, каталог, КП/стекла/покраска, безопасность картинок.

## Найденные вопросы и баги

- `QUESTION`: для 2 рядов заглушки межстекольного `RS107L/RS107R` сейчас считаются симметрично, потому что отдельный параметр "1-я створка изнутри" для 2 ряда отключен. Нужно позднее подтвердить с производством, что для 2 рядов нужны обе стороны, а не односторонняя логика как у 1 ряда.
- `BUG -> FIXED`: в карточке секции для любого СЛАЙД было жестко `1 ряд`, поэтому новая 2-рядная секция отображалась как `1 ряд · 4 пан.`. Исправлено на зависимость от `section.slideRows`.
- `NOTE`: локальный visual QA надо запускать через `http://localhost:5173`; на `127.0.0.1:5173` CORS блокирует stateless preview документов.
