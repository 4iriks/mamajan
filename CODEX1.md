### 3. Саморез DIN7504M

Статус: реализовано.

Файл:

- `Raluma/backend/engine/slide_calc.py`
- `Raluma/backend/tests/test_slide_calc.py`

Что сделано:

- Старое `lb_count * 7 * Q` заменено на расчет от высоты.
- Новая формула в 1-рядной и 2-рядной ветке:

```text
DIN7504M = RU005 * 2 + ceil((H - 200) / 300) * количество_сторон_RS2081 * Q
```

- На ролики формула осталась прежней: `RU005 * 2`.
- Для `H=2400` получается `8` саморезов на одну сторону `RS2081`.
- Если `RS2081` стоит с двух сторон, получается `16` саморезов на `RS2081`, плюс саморезы на ролики.

Покрыто тестами:

- Без `RS2081` -> только ролики.
- Один `RS2081`, `H=2400` -> ролики + 8.
- Два `RS2081`, `H=2400` -> ролики + 16.
- Два `RS2081`, `H=3000` -> расчет меняется по высоте.
- `quantity=2` умножает часть по `RS2081`.

Что важно проверить ревьюеру:

- Не перепутаны `DIN7504M` и `DIN7504O`.
- Не изменена логика саморезов для `RS1082`.
- В 1 ряду и 2 рядах формула одинаково применена.

### 4. `(чертеж)` в заказе стекла

Статус: задача подтверждена, реализация отложена.

Верное правило:

- `(чертеж)` должен ставиться на конкретное физическое стекло/панель, а не на всю секцию.
- Простая замена `_has_glass_drawing(section)` недостаточна, потому что стекла в расчете иногда уже агрегированы.

Важный пример:

- Для 1 ряда левое и правое крайние стекла могут быть одной расчетной строкой `Крайние` с `qty=2`.
- Если чертеж нужен только на левом стекле, из агрегированной строки нельзя понять, какую одну штуку пометить.

Будущий подход:

- Не ломать основной `calculate_slide()`.
- В `project_documents.py` сделать отдельный helper для заказа стекла, который разворачивает расчетные стекла до физических панелей.
- На уровне физической панели определить `(чертеж)`.
- Потом группировать по `(glass_type, width, height, note)`.

Проверить качество при будущей реализации:

- Одинаковые стекла с чертежом и без чертежа должны попасть в разные строки.
- Не размазывать `(чертеж)` на всю секцию.
- Если сторону определить нельзя, зафиксировать правило отдельно, а не угадывать.
